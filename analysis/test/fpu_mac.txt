   - 205 flushed-to-zero subnormal results, 15 wrong values
Directed:
   fma(0x00800000, 0.5, +0)          : expected 0x00400000, got 0x00000000 -> FTZ
   A=9B4E99D0 B=13D13455 C=7AAC7742  : expected 0x7AAC7742, got 0x7AAC773F -> wrong value
Root cause of the wrong values (rtl/FPU_mac.v, Stage 2):
   s2_abs_diff is 8 bits wide but the signed exponent difference E_prod - E_c can exceed
   +/-255, so the alignment shift amount wraps modulo 256 (e.g. -279 -> shift of 23) and a
   tiny product is added as if it were significant. Fix: derive the saturated shift amount
   from the full 10-bit difference.
