----------------------------------------------------------------------------------------------------
Bench   : extra cocotb test on FPU_top (not part of the project suite)
Reference: exact rational arithmetic (Python Fraction) with correct IEEE 754 RNE and
          subnormals, cross-checked against 597,483 host float results (0 mismatches)
Check   : bit-exact (any NaN accepted for NaN); 1 operation per cycle, mixed opcodes

Pipeline (all opcodes): valid_out rises 3 clock edges after the edge that samples valid_in
   (4 register stages); 32 back-to-back ops of each type and a repeating ADD/MUL/FMA/DIV
   sequence all returned in order on consecutive cycles. 1 op/cycle throughput: CONFIRMED.

Normal inputs only, full exponent range (12,000 ops):
   ADD 3,000/3,000 | MUL 2,890/3,000 (FTZ) | FMA 2,981/3,000 (wrong) | DIV 2,860/3,000 (FTZ)
Mixed stimulus, 20,000 back-to-back ops:
   bit-exact 18,638 (93.19%) | subnormal flushed to zero 1,036 (5.18%) | wrong value 326 (1.63%)
Flags on correctly computed results: overflow and div-by-zero always correct; inexact correct
   on all normal-only inputs.

Known deviations from IEEE 754 (see README "Known Limitations"):
   1. No subnormal results (flush-to-zero) in all four units
   2. Subnormal inputs can produce wrong values
   3. FMA alignment wrap-around for large exponent gaps
   4. +0 + -0 returns -0
   5. flag_invalid raised for quiet-NaN inputs
   6. Round-to-nearest-even only

Formal verification: none. No .sby / SymbiYosys files exist; SVA runs in simulation only.

   with timing.sdc constraints. See analysis/asic/asic_analysis.md.
